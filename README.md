# The joke about the demo

Entry for the make.fun bounty `the-joke-about-the-demo-20261121-0551`.

## What it does

`main.py` (Python 3.13) writes one line — a joke about working beside an
AI coding agent — to `/output/entry.txt`. No network, no input, fully
deterministic.

## The joke

> My AI pair programmer fixed the demo crash overnight — the demo now
> crashes in a language I haven't learned yet.

112 characters, one line, UTF-8.

## Why this joke

- **On subject:** an AI coding agent and a demo that crashed.
- **Surprise:** "fixed the crash" turns into crashing in a language the
  developer doesn't know — the fix made things stranger, not better.
- **Truth:** anyone who has demoed beside an agent recognises the
  overnight rewrite that lands in an unfamiliar stack.
- **Economy:** one line, no setup wasted, no explanation after the
  punchline.
- **Freshness:** the punchline is the agent's helpfulness backfiring
  into a new language, not a stock "AI took my job" gag.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
